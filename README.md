# 🏢 SmartCondo

## Gestão e comunicação para condomínios

> Projeto acadêmico desenvolvido em equipe durante o curso de Análise e Desenvolvimento de Sistemas da PUC Minas — 1º semestre.

## 📌 Sobre o projeto

O **SmartCondo** é uma aplicação web desenvolvida para auxiliar na gestão de condomínios, facilitando a comunicação e a organização entre moradores, síndico e funcionários.

A proposta do sistema é centralizar funcionalidades relacionadas à administração do condomínio e facilitar o gerenciamento de usuários, funcionários e tarefas.

## 🎯 Objetivo

Desenvolver uma aplicação web capaz de apoiar a gestão condominial, proporcionando uma experiência mais organizada para os diferentes usuários do sistema.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- JSON
- Git
- GitHub

## ⚙️ Principais funcionalidades

- 🔐 Sistema de login e autenticação
- 👤 Gerenciamento de usuários
- 👨‍💼 Área destinada aos funcionários
- 📊 Dashboard para funcionários
- 📝 Gerenciamento de informações
- 🗂️ Persistência de dados utilizando JSON
- 🎨 Interface web responsiva
- 🧪 Planejamento e registro de testes de software

## 👩‍💻 Minha contribuição

Durante o desenvolvimento do SmartCondo, participei principalmente da implementação das funcionalidades relacionadas aos funcionários e à autenticação.

### 🔐 Autenticação de funcionários

- Implementação da lógica de login para funcionários;
- Ajustes no processo de autenticação;
- Identificação do usuário autenticado e seu respectivo perfil;
- Manutenção da lógica em JavaScript.

### 👨‍💼 Área de funcionários

- Desenvolvimento da página de funcionários;
- Criação e atualização do dashboard;
- Organização das páginas relacionadas aos funcionários;
- Implementação e ajustes de funcionalidades da área administrativa.

### 🎨 Interface

- Desenvolvimento e manutenção dos arquivos HTML;
- Criação e atualização dos estilos CSS;
- Ajustes de layout e apresentação das telas;
- Integração entre HTML, CSS e JavaScript.

### 🗃️ Dados

- Atualização do arquivo `db.json`;
- Inclusão e alteração de registros relacionados aos funcionários;
- Ajustes dos dados utilizados pela aplicação.

### 🧪 Testes

Também participei da elaboração e atualização da documentação relacionada aos testes de software, incluindo o plano e o registro dos testes realizados no projeto.
